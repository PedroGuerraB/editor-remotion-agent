# Editor Remotion Agent

AI senior video editor agent powered by Remotion.js.

## Usage

After human validation of a creative brief, invoke `/remotion` to produce a fully edited video with captions, headlines, visual/audio effects, cuts, and CTA.

## Stack

- [Remotion](https://remotion.dev) v4.0.472
- React 19
- Bundled ffmpeg via `@remotion/compositor-darwin-arm64`

## AG Kit Skills

- `remotion-video-editor` — semantic-first video editing skill
- `/remotion` workflow — full pipeline from brief to final video

## Philosophy

> Every edit decision flows from the creative semantics. No fixed templates.
